# GeoPoliticalMedia — Logo concepts v1

First numbered round for the independent news blog, vlog, video channel and studio. This round uses prominent red with deep navy and white. The approved G/Earth/red-orbit artwork in `dist/assets/` and the earlier `public/assets/concepts/` archive remain intact.

## Directions

| Concept | Idea | Likely use |
| --- | --- | --- |
| **01 · Orbital G** | Continues the existing G + Earth + red orbit in simplified vector geometry. White meridians replace photographic terrain; the red orbit stays prominent. | Primary identity, channel avatar, global affairs section. |
| **02 · Studio Frame** | Red viewfinder corners, a navy camera lens, white play aperture and red live indicator. | Studio identity, video watermark, recording graphics. |
| **03 · Editorial GPM** | Custom GPM lettering inside a red masthead tile, with a folded corner and editorial rules. | News favicon, publication stamp, title slate. |

## Files

Each direction has a transparent **icon SVG**, a transparent **wordmark SVG**, and matching **PNG previews**. Full lockups use the exact display name **GeoPoliticalMedia**. `04-comparison.svg` and `04-comparison.png` show the three directions with light and inverse dark presentations.

## Palette and editing

- Signal red: `#E52539`
- Deep navy: `#0B1A2B`
- White: `#FFFFFF`

All marks are editable native SVG paths, circles and strokes. The wordmark uses live text with Arial, Helvetica and sans-serif fallbacks; the GPM monogram itself is drawn from paths. Keep the wordmark editable during exploration and outline its type in a design editor before production export if exact cross-device typography is required. The comparison board contains inverse color examples; its navy backgrounds are presentation surfaces, not part of the transparent master canvases.

No application code or deployed identity was changed. Continue the next round in `assets/concepts/logos/v2/` and preserve this round.
