# Coordinate icon collection

Sixteen variations developed from the selected Coordinate GC monogram. All artwork is requested as standalone symbols without a company wordmark, with light marks on dark backgrounds.

[Open gallery](index.html) · [Download all 16 PNGs](coordinate-icons.zip)

New: [Arctic Coordinate + Earth](earth/index.html) adds eight icon-only variations combining the selected Arctic mark with the approved Americas-facing planet.

The first four explore color around the selected construction; the next four introduce new geometric concepts; the next four vary spacing, weight, and interlocking arcs; the last four explore material, edge details, and an app badge.

Built-in image generation only; no paid APIs or purchases. Each native PNG has a matching `.prompt.md` file containing its exact generation instructions. The original reference remains in the parent directory.
