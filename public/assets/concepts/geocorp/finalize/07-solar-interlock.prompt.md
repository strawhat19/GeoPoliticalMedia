# Solar Interlock

Use case: logo-brand
Asset type: standalone square company logo icon
Input image: design-family reference only. Use ONLY the upper GC monogram from the reference. Remove the entire company-name wordmark and all lettering below it.
Primary request: Create ONE new GC icon variant derived from that upper monogram.
Concept: A meaningfully new offset interlocking GC mark built from broad circular ivory arcs. Interlock one outer C and one inner readable G with a strong horizontal bar, carefully offset for a new silhouette but still a single coherent compact monogram. Clean broad negative-space channels. Add one restrained amber-orange arc segment and a small matching orange coordinate corner at the upper-right. Flat precise elegant geometric icon, not metallic or glowing.
Composition: one centered standalone monogram, approximately 68% of square canvas width, equal generous margins on all sides; re-center the mark vertically now that the wordmark is absent. Straight-on graphic, no perspective, no mockup.
Background: fully opaque solid deep navy #06121F across the ENTIRE square canvas; no transparency, no checkerboard.
Style: crisp flat vector-like filled geometry, polished optical spacing, calm professional identity suited to a space-themed dark website. Sharp clean edges, no texture, no heavy glow, no drop shadow.
Text: NONE. No company name, no wordmark, no geocorp.io, no .io, no caption, no title, no number, no labels, no watermark. G and C exist only as the integrated monogram shape. No other lettering.
Deliverable: ONE square raster image containing ONLY the standalone icon and navy background. No contact sheet, no variants grid, no presentation board.
