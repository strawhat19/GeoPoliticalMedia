# Mint Soft Square

Use case: logo-brand
Asset type: standalone square company logo icon
Input image: design-family reference only. Use ONLY the upper GC monogram from the reference. Remove the entire company-name wordmark and all lettering below it.
Primary request: Create ONE new GC icon variant derived from that upper monogram.
Concept: Redesign the circular monogram into a structural soft-square GC: an outer almost-closed C contour made from a square with large rounded corners, wrapped around a nested clearly readable rounded-square G with a broad horizontal bar. Keep generous even negative-space channels and the reference's small detached coordinate bracket near the upper-right aperture. Pale mint-white primary strokes, vivid mint green bracket. Sleek slightly softer app silhouette, stable and substantial.

Text: NONE. No company name, no wordmark, no geocorp.io, no .io, no caption, no title, no number, no labels, no watermark. G and C exist only as the integrated monogram shape. No other lettering.
Deliverable: ONE square raster image containing ONLY the standalone icon and navy background. No contact sheet, no variants grid, no presentation board.
